# Kanban Task Board

A simple Kanban task management application built with React and Tailwind CSS.

The project is inspired by tools such as Trello and is being developed as a learning project to practice React fundamentals, component architecture, state management, props, forms, and browser storage.

## 🚀 Features

- Create tasks
- Edit task titles
- Mark tasks as completed
- Organize tasks into different Kanban columns
- Cancel task editing
- Select a column when creating a task
- Store tasks locally using `localStorage`
- Display tasks dynamically based on their column
- Modal-style interface for creating tasks
- Responsive UI built with Tailwind CSS

## 🛠️ Technologies

- React
- JavaScript
- Tailwind CSS
- Vite
- Lucide React
- LocalStorage
